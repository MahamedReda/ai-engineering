Python for Java Developers

Everything you need from Python for AI engineering, explained by comparing it with Java. Eight short parts, two weeks, then you are ready for the repo lessons.

How to use this guide

  1. Read one part (20–30 minutes). The Java and Python examples are side by side.
  2. Type every Python example into the interactive prompt. Don't copy and paste; typing builds the habit.
  3. Do the exercises at the end of the part, in your ai-journey repo.
  4. Then read the linked official chapter. It will be quick, because you already know the idea. The links open the offline copy in official-html, which is next to this file.

Parts 1–4 are week 1 and parts 5–8 are week 2. The full official tutorial is also in this folder as Python-3.13-Tutorial.pdf if you prefer to read on paper or a tablet.

1 · Running Python

Python has no compile step and no main class. You run a file directly, or type code into an interactive prompt (the REPL) and see results immediately.

The interactive prompt

# Windows                      # Mac
python                         python3

>>> 2 + 3
5
>>> "hello".upper()
'HELLO'
>>> exit()

Keep a prompt open while you read. It is the fastest way to answer "what does this do?"

A script, and the "main method"

JAVA

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}
// javac Hello.java && java Hello

PYTHON · hello.py

def main() -> None:
    print("Hello")


if __name__ == "__main__":
    main()

# python hello.py

if __name__ == "__main__": means "only run this when the file is executed directly, not when another file imports it." You will see it at the bottom of almost every repo lesson.

2 · Syntax and types

Indentation replaces braces, and variables have no declared types. Values still have strict types, though: "1" + 1 is an error, not "11".

JAVA

int count = 3;
String name = "Reda";
final double RATE = 0.2;
String nothing = null;

if (count > 0 && name != null) {
    System.out.println("Hi " + name + ", " + count);
} else if (count == 0) {
    System.out.println("zero");
}

int half = 7 / 2;        // 3
double exact = 7 / 2.0;  // 3.5
boolean same = a.equals(b);

PYTHON

count = 3
name = "Reda"
RATE = 0.2          # constant by naming convention only
nothing = None

if count > 0 and name is not None:
    print(f"Hi {name}, {count}")
elif count == 0:
    print("zero")


half = 7 // 2       # 3
exact = 7 / 2       # 3.5  (/ always gives a float)
same = a == b       # == compares values, like equals()

What is different

  • Blocks are indentation (4 spaces). A colon : starts a block. No semicolons.
  • and, or, not instead of &&, ||, !. True, False and None are capitalized.
  • == compares values; is compares identity. Use is only with None: if x is None:.
  • Integers never overflow. 2 ** 100 just works (** is the power operator).
  • Truthiness: 0, "", [], {} and None count as false. if items: means "if the list is not empty."

Strings

name = "Ada"
greeting = f"Hello {name}, you have {3 * 2} messages"   # f-string: like String.format, but inline
text = """Multi-line
string"""                                              # like Java text blocks
"python"[0]        # 'p'
"python"[-1]       # 'n'   negative index counts from the end
"python"[0:3]      # 'pyt' slicing: start inclusive, end exclusive
len("python")      # 6     len() works on strings, lists, dicts, everything
"a,b,c".split(",") # ['a', 'b', 'c']
" ".join(["a", "b"])  # 'a b'   join is a method on the separator
"  hi ".strip()    # 'hi'

3 · Control flow and functions

JAVA

for (int i = 0; i < 5; i++) { ... }

for (String w : words) { ... }

for (int i = 0; i < words.size(); i++) {
    System.out.println(i + " " + words.get(i));
}

switch (status) {
    case 200 -> ok();
    case 404 -> missing();
    default  -> fail();
}

PYTHON

for i in range(5): ...

for w in words: ...

for i, w in enumerate(words):
    print(i, w)


for name, score in zip(names, scores): ...   # walk two lists together

match status:
    case 200: ok()
    case 404: missing()
    case _:   fail()

There is no i++; write i += 1. while, break and continue work as in Java.

Functions

def top_words(text: str, n: int = 10, lowercase: bool = True) -> list[str]:
    """Return the n most common words.  (This string is the function's documentation.)"""
    if lowercase:
        text = text.lower()
    ...

top_words(doc)                      # defaults are used
top_words(doc, 5)
top_words(doc, n=5, lowercase=False)   # keyword arguments: clear, any order

def stats(numbers: list[float]) -> tuple[float, float]:
    return min(numbers), max(numbers)    # return several values as a tuple

low, high = stats([3, 1, 4])             # and unpack them
  • Default and keyword arguments replace overloading. One function, many ways to call it.
  • Functions are values. Pass them around like a Function<T,R>: sorted(words, key=len).
  • Lambdas are one expression only: key=lambda w: w.lower().
  • *args collects extra positional arguments into a tuple and **kwargs collects keyword arguments into a dict. You'll see them in library code.

The classic trap

Never use a mutable default like def add(item, items=[]). The list is created once and shared between calls. Write items: list | None = None, then if items is None: items = [].

Comprehensions replace most streams

JAVA

List<Integer> doubled = nums.stream()
    .filter(x -> x > 0)
    .map(x -> x * 2)
    .collect(Collectors.toList());

Map<String, Integer> lengths = words.stream()
    .collect(Collectors.toMap(w -> w, String::length));

PYTHON

doubled = [x * 2 for x in nums if x > 0]




lengths = {w: len(w) for w in words}


unique = {w.lower() for w in words}     # set comprehension

Read a comprehension right to left: "for each x in nums, if x > 0, keep x * 2." Also useful: sum(), min(), max(items, key=...), any() and all().

5 · Modules, files, JSON and errors

Modules and packages

Every .py file is a module and every folder of modules is a package. There is no classpath: Python looks in the current folder and in the active .venv.

# project/
#   app/
#     __init__.py      (marks a package; can be empty)
#     text_utils.py
#   main.py

import json                              # whole module:  json.dumps(...)
from pathlib import Path                 # one name
from app.text_utils import top_words     # your own code

Files: with is try-with-resources

JAVA

try (var reader = Files.newBufferedReader(path)) {
    String line;
    while ((line = reader.readLine()) != null) {
        process(line);
    }
}

PYTHON

with open("notes.txt", encoding="utf-8") as f:
    for line in f:
        process(line.rstrip("\n"))

# or simply:
text = Path("notes.txt").read_text(encoding="utf-8")

Always pass encoding="utf-8". Windows otherwise uses a different default, and your code will behave differently on your two machines.

JSON: you'll use it every day with LLMs

import json

data = json.loads('{"name": "Ada", "skills": ["math", "code"]}')   # str  -> dict
data["skills"][0]                                                    # 'math'
text = json.dumps(data, indent=2)                                    # dict -> str
Path("out.json").write_text(text, encoding="utf-8")

Exceptions: all unchecked

try:
    value = int(user_input)
except ValueError as e:
    print(f"Not a number: {e}")
else:
    print("parsed fine")        # runs only if no exception
finally:
    print("always runs")

class QuotaExceeded(Exception):  # custom exception
    pass

raise QuotaExceeded("monthly token budget used up")

Python style is "easier to ask forgiveness than permission": try the operation and catch the failure, instead of checking everything first.

6 · Classes and dataclasses

Classes exist, but Python uses far fewer of them than Java. If something has no state, make it a function in a module.

JAVA

public record Message(String role, String content) {}

public class Conversation {
    private final List<Message> messages = new ArrayList<>();
    private final String system;

    public Conversation(String system) {
        this.system = system;
    }

    public void add(String role, String text) {
        messages.add(new Message(role, text));
    }

    public int size() { return messages.size(); }
}

PYTHON

from dataclasses import dataclass, field


@dataclass(frozen=True)
class Message:
    role: str
    content: str


@dataclass
class Conversation:
    system: str
    messages: list[Message] = field(default_factory=list)

    def add(self, role: str, text: str) -> None:
        self.messages.append(Message(role, text))

    @property
    def size(self) -> int:
        return len(self.messages)
  • @dataclass is your record or Lombok. It generates __init__, __repr__ (toString) and __eq__ (equals). frozen=True makes it immutable.
  • self is explicit. It is the first parameter of every method, and you write self.x, never just x.
  • Nothing is private. A leading underscore (_cache) means "internal, please don't touch."
  • @property turns a method into a read-only attribute: conv.size, not conv.getSize().
  • Interfaces: usually just duck typing ("if it has a .complete() method, it works"). When you want it explicit, use typing.Protocol or abc.ABC.
  • Special methods like __len__, __iter__ and __str__ plug your class into len(), for loops and print().

Exercises

  1. Build the Conversation class above, add three messages, and print() it. Notice the free __repr__.
  2. Add a method to_json(self) -> str using dataclasses.asdict and json.dumps. This is the exact shape of an LLM API request body.
  3. Write a Protocol called Model with complete(self, prompt: str) -> str, plus a fake class that returns "ok". The repo lessons use this pattern a lot.

7 · Type hints and tests

Type hints: documentation that tools can check

def find_user(user_id: int, cache: dict[int, str] | None = None) -> str | None:
    ...

from collections.abc import Callable
Handler = Callable[[str], str]           # a type alias, like Function<String,String>

Python does not enforce hints when your code runs; they are for you, your editor and a type checker. Install one in your own environment (pip install mypy, then mypy file.py) to get compiler-like errors. Use hints on every function signature, as the repo does.

unittest is JUnit

JAVA · JUnit 5

class TextUtilsTest {
    @Test
    void countsWords() {
        assertEquals(2, count("a b"));
    }

    @Test
    void rejectsNull() {
        assertThrows(IllegalArgumentException.class,
                     () -> count(null));
    }
}

PYTHON · tests/test_text_utils.py

import unittest
from app.text_utils import count


class TextUtilsTest(unittest.TestCase):
    def test_counts_words(self) -> None:
        self.assertEqual(count("a b"), 2)

    def test_rejects_none(self) -> None:
        with self.assertRaises(ValueError):
            count(None)


if __name__ == "__main__":
    unittest.main()

Run every test in the tests folder with the same command the repo uses: python -m unittest discover tests -v. Test files must start with test_. Many teams use pytest instead, which is shorter, but unittest is built in and is what the curriculum expects.

8 · Idioms you will see in AI code

Generators: values produced one at a time

LLM responses are streamed token by token, and generators are how Python models a stream.

def chunks(text: str, size: int):
    for i in range(0, len(text), size):
        yield text[i:i + size]          # pauses here, resumes on the next request

for piece in chunks(document, 500):     # used for splitting documents in RAG
    embed(piece)

async / await: like CompletableFuture, but readable

import asyncio

async def ask(question: str) -> str:
    await asyncio.sleep(1)              # stands in for a network call
    return f"answer to {question}"

async def main() -> None:
    answers = await asyncio.gather(ask("a"), ask("b"), ask("c"))   # run concurrently
    print(answers)                       # done in about 1 second, not 3

asyncio.run(main())

You'll meet this in agent and server code (weeks 9–10). Python-asyncio-overview.pdf in this folder explains the model in more depth.
